> HydCraft，讀作 /ˈhaɪd.kræft/，中文名「氫氣工藝」，一般簡稱「氫氣」。氫氣工藝是一個圍繞城市建設、鐵路交通的 Minecraft 伺服器。伺服器成立於 2018 年 9 月 1 日，目前為第八周目，運行在 NeoForge 1.21.1，主要玩法模組包括 MTR 4 與機械動力。

本站是氫氣工藝的中央入口與統一入口，用於整理伺服器相關資訊、公開服務、狀態監控、地圖入口和社群資料。未來，這裡也會逐漸整合玩家資料、帳號綁定、伺服器狀態和更多社群系統。更詳細的規則、教學與資料會繼續放在 Wiki 和 Docs 中維護；更完整的伺服器歷史，則可以在「歷程」頁面中閱讀。

此前曾有化工、氫能或管道建設相關從業者誤以為本站提供相關業務，故在此再次說明：**本站（氫氣工藝）不從事氫氣管道建設、化工生產或工業工程相關服務**。氫氣工藝是面向 Minecraft 玩家之社群與遊戲伺服器，並非化工、管道或工業工程專案。

至於為什麼用一個化學元素給創造模式伺服器命名？因為這個名字最早來源於玩家的一句玩笑「一加的手機系統叫氫 OS，要不就叫這個？」後來，這個隨口起出的名字在 2018 年 11 月成為伺服器的正式名稱，並一直沿用至今。

本站基於 Nuxt 全端框架開發，專案倉庫可以在 [GitHub](https://github.com/AurLemon/hydcraft-portal) 查看。熟悉站長其他專案的朋友可能會發現，本站的 UI 風格與 [AurLemon Intro](https://aurlemon.top) 保持了相近的視覺語言。

- Nuxt 3 + TypeScript
- Nuxt UI + Tailwind CSS + Motion-V
- GitHub Actions + 騰訊雲 EdgeOne

同時，我們也歡迎各類 Minecraft 社群、伺服器團隊及相關技術愛好者與氫氣工藝交流合作，建立友好關係或互換友情連結。若您希望與我們建立聯繫，歡迎透過本站公布的聯絡方式與我們溝通。
