HydCraft。発音は /ˈhaɪd.kræft/、中国語名は「氢气工艺」、ふだんは「氢气」と略して呼ばれています。HydCraft は、都市建設と鉄道交通を中心とした Minecraft サーバーです。サーバーは 2018 年 9 月 1 日に設立され、現在は Forge 1.20.1 で稼働しており、主な導入 Mod は MTR と Create です。

では、なぜクリエイティブ中心のサーバーに化学元素の名前を付けたのか。もともとは、あるプレイヤーの冗談がきっかけでした。「OnePlus のスマホ OS が Hydrogen OS なら、これでいいんじゃない？」。そんな軽いノリで出た名前が、2018 年 11 月に正式名称となり、そのまま今まで使われ続けています。

このサイトは HydCraft の Hydroline ID サイトです。サーバー関連情報、公開サービス、ステータス監視、マップ入口、コミュニティ資料を整理するために作られました。今後はプレイヤー情報、アカウント連携、サーバー状態、さらに多くのコミュニティ機能もここへ順次統合していく予定です。

より詳しいルール、チュートリアル、資料は引き続き Wiki と Docs で管理しています。サーバーの歴史をよりまとまった形で知りたいなら、「歩み」ページを読んでください。

このサイトは Nuxt フルスタックフレームワークをベースに開発されています。プロジェクトのリポジトリは [GitHub](https://github.com/AurLemon/hydcraft-portal) で公開しています。管理人のほかのプロジェクトを知っている人なら、UI の雰囲気が [AurLemon Intro](https://aurlemon.top) と近いことに気づくかもしれません。

- Nuxt 3 + TypeScript
- Nuxt UI + Tailwind CSS + Motion-V
- GitHub Actions + Tencent Cloud EdgeOne
