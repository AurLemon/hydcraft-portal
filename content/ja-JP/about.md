> HydCraft。発音は /ˈhaɪd.kræft/、中国語名は「氢气工艺」で、ふだんは「氢气」と略して呼ばれています。HydCraft は、都市建設と鉄道交通を中心とした Minecraft サーバーです。サーバーは 2018 年 9 月 1 日に設立され、現在は Forge 1.20.1 で稼働しており、主な導入 Mod は MTR と Create です。

このサイトは HydCraft の中央入口であり、統合ポータルです。サーバー関連情報、公開サービス、ステータス監視、マップ入口、コミュニティ資料を整理するために作られました。今後はプレイヤー情報、アカウント連携、サーバー状態、さらに多くのコミュニティ機能もここへ順次統合していく予定です。より詳しいルール、チュートリアル、資料は引き続き Wiki と Docs で管理しています。より完全なサーバーの歴史は、「歩み」ページで読むことができます。

以前、化学工学、水素エネルギー、パイプライン建設の関係者の方に、このサイトが関連業務を提供していると誤解されたことがあったため、ここで改めて明記します。**このサイト（HydCraft）は、水素パイプライン建設、化学製造、または土木・産業工学関連のサービスを提供していません。** HydCraft は Minecraft プレイヤー向けのコミュニティおよびゲームサーバーであり、化学工学・パイプライン・産業工学のプロジェクトではありません。

では、なぜクリエイティブ中心のサーバーに化学元素の名前を付けたのか。もともとは、あるプレイヤーの冗談がきっかけでした。「OnePlus のスマホ OS が Hydrogen OS なら、これでいいんじゃない？」。その軽い発想から生まれた名前が、2018 年 11 月に正式名称となり、そのまま今まで使われ続けています。

このサイトは Nuxt フルスタックフレームワークをベースに開発されています。プロジェクトのリポジトリは [GitHub](https://github.com/AurLemon/hydcraft-portal) で公開しています。管理人のほかのプロジェクトを知っている人なら、UI の雰囲気が [AurLemon Intro](https://aurlemon.top) と近いことに気づくかもしれません。

- Nuxt 3 + TypeScript
- Nuxt UI + Tailwind CSS + Motion-V
- GitHub Actions + Tencent Cloud EdgeOne

同時に、Minecraft の各種コミュニティ、サーバーチーム、および関連技術に関心のある方々が HydCraft と交流・協力し、友好的な関係を築いたり、相互にリンクを交換したりすることも歓迎します。ご連絡をご希望の場合は、当サイトに掲載している連絡方法からお気軽にお問い合わせください。
