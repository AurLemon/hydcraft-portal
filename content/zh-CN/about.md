> HydCraft，读作 /ˈhaɪd.kræft/，中文名「氢气工艺」，一般简称「氢气」。氢气工艺是一个围绕城市建设、铁路交通的 Minecraft 服务器。服务器成立于 2018 年 9 月 1 日，当前为第八周目（NeoForge 1.21.1），主要玩法模组包括 MTR 4 与机械动力。

本站是 Minecraft 服务器氢气工艺的门户站和统一入口，用于整理服务器相关信息、公开服务、状态监控、地图入口和社区资料。未来，这里也会逐渐整合玩家资料、账号绑定、服务器状态和更多社区系统。更详细的规则、教程与资料会继续放在 Wiki 和 Docs 中维护，更完整的服务器历史，则可以在「历程」页面中阅读。

此前曾有化工、氢能或管道建设相关从业者误以为本站提供相关业务，故在此再次说明：**本站（氢气工艺）不从事氢气管道建设、化工生产或工业工程相关服务**。氢气工艺是面向 Minecraft 玩家的社区与游戏服务器，并非化工、管道或工业工程项目。

至于为什么用一个化学元素给创造模式服务器命名？因为这个名字最早来源于玩家的一句玩笑「一加的手机系统叫氢 OS，要不就叫这个？」后来，这个随口起出的名字在 2018 年 11 月成为服务器的正式名称，并一直沿用至今。

本站基于 Nuxt 全栈框架开发，项目仓库可以在 [GitHub](https://github.com/AurLemon/hydcraft-portal) 查看。熟悉站长其他项目的朋友可能会发现，本站的 UI 风格与 [AurLemon Intro](https://aurlemon.top) 保持了相近的视觉语言。项目所涉及的技术栈如下：

- Nuxt 4 + TypeScript
- Nuxt UI + Tailwind CSS + Motion-V
- GitHub Actions + 腾讯云 EdgeOne

同时，我们也欢迎各类 Minecraft 社区、服务器团队及相关技术爱好者与氢气工艺交流合作，建立友好关系或互换友情链接。若您希望与我们建立联系，欢迎通过本站公布的联系方式与我们沟通。
