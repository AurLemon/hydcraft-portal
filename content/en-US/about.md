> HydCraft, pronounced /ˈhaɪd.kræft/, is known in Chinese as "氢气工艺" and is usually shortened to "氢气". HydCraft is a Minecraft server focused on city building and railway transportation. The server was founded on September 1, 2018, and currently runs on Forge 1.20.1. Its main gameplay mods include MTR and Create.

This site is the central entry point and unified portal for HydCraft. It organizes server-related information, public services, status monitoring, map entry points, and community resources. In the future, it will also gradually integrate player profiles, account binding, server status, and more community systems. More detailed rules, tutorials, and references will continue to be maintained in the Wiki and Docs. A more complete server history can be read on the "Timeline" page.

There was once confusion from people in chemical engineering, hydrogen energy, or pipeline construction who assumed this site provided related services, so this needs to be stated again: **this site (HydCraft) does not provide hydrogen pipeline construction, chemical production, or industrial engineering services**. HydCraft is a community and game server for Minecraft players, not a chemical engineering, pipeline, or industrial engineering project.

Why give a creative-mode server a name from a chemical element? The name originally came from a player's joke: "OnePlus phones have a system called Hydrogen OS, why not just call it that?" Later, this casually coined name became the server's official title in November 2018, and it has remained in use ever since.

This site is built with Nuxt. The project repository is available on [GitHub](https://github.com/AurLemon/hydcraft-portal). Friends familiar with the maintainer's other projects may notice that the UI style shares a similar visual language with [AurLemon Intro](https://aurlemon.top).

- Nuxt 3 + TypeScript
- Nuxt UI + Tailwind CSS + Motion-V
- GitHub Actions + Tencent Cloud EdgeOne

At the same time, we also welcome all kinds of Minecraft communities, server teams, and related technical enthusiasts to exchange and cooperate with HydCraft, build friendly relationships, or swap links. If you would like to get in touch with us, please feel free to contact us through the methods published on this site.
